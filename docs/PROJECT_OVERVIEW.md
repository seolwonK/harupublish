# Haru Project Overview

## 서비스 개요

Haru는 한국어 및 한국 문화 관련 분야의 전문가와 글로벌 학습자를 연결하는 1:1 온라인 레슨 플랫폼이다. 사용자는 전문가 프로필을 탐색하고, 가능한 시간대를 선택해 레슨을 예약하고, 결제 후 Jitsi Meet 기반 화상 수업에 참여한다.

PPT 기준 MVP는 "오늘 나에게 맞는 한국 튜터를 찾고 예약한다"는 흐름에 집중한다. 차별화 포인트는 한국 전문가 중심의 레슨, 한국어/한국 문화 분야 특화, 향후 일대다 실시간 강연 확장 가능성이다.

## 핵심 사용자

### Student

- 전문가를 탐색하고 레슨을 예약하는 고객
- 프로필, 예약, 완료 수업, 채팅, 결제 내역을 관리
- 수업 완료 후 리뷰 작성 또는 이슈 신고 가능

### Tutor

- 처음에는 일반 고객 계정으로 가입하고, 역할 전환을 통해 전문가 모드 사용
- 레슨 프로필, 가능 스케줄, 가격, 소개 영상, 지급 수단을 등록
- 예약된 수업을 진행하고 완료 수업 및 수익을 확인

### Admin

- 회원, 전문가 승인, 예약/세션, 결제/정산, 신고/후기, 고객센터, 통계를 관리
- 수업 녹화본 접근 및 운영 검토를 수행

## MVP 목표

- 사용자가 로그인 후 전문가 목록과 상세 프로필을 보고 1:1 레슨을 예약할 수 있다.
- 튜터가 레슨 프로필, 가능 시간, 가격, 지급 수단을 등록하고 관리자 승인 대상으로 제출할 수 있다.
- 예약, 변경, 취소, 수업 입장, 완료 처리의 기본 플로우를 제공한다.
- 결제와 정산은 실제 지급/송금 자동화보다 상태 관리와 운영 기준을 우선 정의한다.
- 채팅과 이메일 알림을 통해 예약/변경/취소/수업 리마인더를 전달한다.
- 관리자가 MVP 운영에 필요한 최소 승인, 회원, 예약, 결제, 신고 정보를 확인할 수 있다.

## 주요 기능 요약

- Auth/User: 로그인, 회원가입, 소셜 로그인 후보, 프로필 설정, 역할 전환
- Tutor Profile: 전문가 소개, 영상, 가능한 언어, 카테고리, 가격, 가능 시간, 초기 리뷰
- Schedule/Booking: 25분/50분 수업, 30분 단위 예약, 시간대 자동 표시, 변경/취소
- Payment: 1회/5회/10회권 구매, 학생 결제 수수료, 할인 정책
- Settlement: 수업 완료 후 튜터 수익 반영, 플랫폼 수수료, 월 1회 인출 기준
- Chat/Notification: 학생-강사 채팅, 예약 알림, 30분 전 리마인더, 이메일 알림
- Review/Report: 수업 완료 후 리뷰 작성, 문제 신고 및 관리자 검토
- Admin: 대시보드, 회원 관리, 전문가 승인, 레슨 관리, 결제/정산 관리, 신고/후기 관리
- Video Session: Jitsi Meet 기반 수업 입장, 수업 녹화본 관리자 확인

## MVP 포함 범위

- 1:1 레슨만 지원
- 학생/튜터/Admin 역할 구조
- 고객 로그인 후 전문가 전환
- 전문가 프로필 등록 및 관리자 승인
- 전문가 목록과 상세 프로필 조회
- 25분/50분 레슨 옵션과 튜터가 설정한 가격
- 30분 단위 가능 시간 등록 및 예약
- 수업 시작 10분 전부터 입장 허용
- 수업 3시간 전까지 변경/취소 허용
- 예약/변경/취소/30분 전 리마인더 이메일 알림
- 수업 완료 확인, 이슈 신고, 리뷰 작성
- 수업 완료 후 튜터 수익 반영 상태 관리
- 관리자용 핵심 운영 데이터 조회

## MVP 제외 범위

- 일대다 실시간 강연
- Trial lesson
- 언어 레벨 선택
- 검색창, 고급 필터링, 카테고리 기반 추천
- 튜터 접속 상태 표시
- Read/Unread 채팅 상태
- 휴대폰 푸시 알림 연동
- 실제 자동 송금 실행
- 카테고리별 고급 통계/분석
- 공지/FAQ/프로모션/배너 관리
- 튜터 취소율, 참여율 공개 및 고급 패널티 정책

## 전체 서비스 흐름

1. 사용자는 메인 화면에서 전문가 목록을 확인한다.
2. 전문가 상세 페이지에서 소개, 영상, 가능한 언어, 리뷰, 가격, 가능 시간을 확인한다.
3. 미로그인 사용자가 예약 또는 메시지를 시도하면 로그인/회원가입 화면으로 이동한다.
4. 로그인 사용자는 수업 시간과 25분/50분 옵션을 선택하고 결제한다.
5. 결제 완료 후 예약이 생성되고 학생과 튜터에게 알림이 발송된다.
6. 학생과 튜터는 My Bookings 또는 예약 현황에서 수업을 확인한다.
7. 수업 시작 30분 전 리마인더가 발송되고, 10분 전부터 Jitsi Meet 수업 입장이 가능하다.
8. 변경/취소는 수업 3시간 전까지 사유 입력 후 처리한다.
9. 수업 종료 후 학생은 완료 확인 또는 이슈 신고를 선택한다.
10. 완료 확인 또는 일정 시간 경과 후 튜터 수익에 반영된다. 이슈가 있으면 관리자 검토 대상으로 둔다.
11. 학생은 완료한 수업에 대해 리뷰를 작성할 수 있다.
12. 관리자는 회원, 튜터 승인, 예약, 결제/정산, 신고/후기, 녹화본을 운영 관리한다.
