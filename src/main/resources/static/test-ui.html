프로필 수정

현재 모드(activeRole)

로그인 직후에는 STUDENT만 보유합니다. TUTOR 모드는 튜터 전환 후 선택할 수 있습니다.

승인 여부는 activeRole이 아니라 tutorProfileStatus로 판단합니다.

튜터 전환과 프로필

튜터 전환은 모드 진입, 프로필 저장은 임시저장, 승인요청은 관리자 심사 요청입니다.

1. 튜터 전환 roles에 TUTOR를 추가하고 activeRole을 TUTOR로 바꿉니다. 아직 판매 가능 상태는 아닙니다.
2. 프로필 임시저장 작성 내용을 DRAFT 상태로 저장합니다. 고객 Experts 목록에는 노출되지 않습니다.
3. 승인요청 제출 필수값이 채워지면 PENDING으로 바뀝니다. 관리자가 APPROVED 처리해야 노출됩니다.

실패 케이스 테스트

필수값이 빠진 프로필은 저장은 될 수 있지만 승인요청 제출은 실패해야 합니다.
